# CX_3803_DCC_6342_TSA

CX 3803 Capstone repository for Team 6342: **Cascade Springs Smart GIS**, a mobile application for preserve navigation, sustainability education, and geotagged field reporting.

Start with the [project specifications](docs/README.md) for the architecture, data model, interfaces, security requirements, offline behavior, and user experience.

For the local Cloudflare Workers API, Docker PostGIS, and Drizzle setup, follow
the [backend setup guide](backend/README.md).

Use the existing [Figma prototype](https://www.figma.com/design/zotPKNdYIDv72Bc1mc57CQ/mid-fidelity-prototype?node-id=0-1) for UI design and the [Jira backlog](https://gatech-team-f1s41wh9.atlassian.net/jira/software/projects/J6/boards/2/backlog) for implementation tracking.
